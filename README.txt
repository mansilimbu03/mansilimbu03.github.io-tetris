BLOCKFALL — GitHub Pages upload

1. Extract the ZIP.
2. Create a PUBLIC repository on GitHub (for example: tetris-game).
3. Choose Add file > Upload files and drag index.html, style.css, game.js into the repository ROOT.
4. Commit changes.
5. Settings > Pages > Build and deployment > Deploy from a branch > main > /(root) > Save.
6. Visit https://YOUR-USERNAME.github.io/tetris-game/ after publishing finishes.

You can also play locally by opening index.html in a browser.
No external dependencies, no tracking, and no backend required.
